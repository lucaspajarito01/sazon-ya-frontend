# SazónYA Frontend (`sazon-ya-frontend`)

Interfaz web **Zero-Bloat** construida exclusivamente con **HTML5**, **CSS3** (Paleta *«Sazón & Brasa»*) y **JavaScript Puro (ES Modules ES2022+)** para animaciones e interacción con la API REST de SazónYA.

## Arquitectura Modular (`src/`)
- `src/html/index.html` & `index.html`
- `src/css/styles.css`
- `src/Js/config.js`
- `src/Js/roles.js`
- `src/Js/session.js`
- `src/Js/api.js`
- `src/Js/ui.js`
- `src/Js/app.js`

## Comandos

```bash
npm start
npm test
```
